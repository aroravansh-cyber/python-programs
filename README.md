# Python Programs 🐍

A collection of Python programs and beginner-level projects created while learning and practicing Python programming.

## 📂 Projects & Programs

- 🧮 **Matrix Calculator** — Performs matrix-related calculations.
- 👨‍💼 **Employee Data Management** — Manages basic employee information.
- 🎯 **Number Guess Game** — A simple number guessing game.
- ✊ **Rock Paper** — A basic Rock-Paper-Scissors game.
- 🐾 **Animal ASCII** — Displays animals using ASCII characters.
- 🎲 **Dogging Table Game** — A simple Python-based game.
- 🔢 **Pattern** — Generates different patterns using Python.
- 📱 **QR Generator** — Generates QR codes using Python.
- ✖️ **Table** — Generates multiplication tables.

## 🛠️ Technologies

- Python 3
- VS Code
